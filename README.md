# Full-Survey-Project-
Core Features:

👤 User Management

    Sign up & login

    Edit profile

    Manage account

📊 Survey System

    Create surveys with questions & answers

    Edit/update your surveys

    Delete surveys

    View all surveys

🗳️ Voting

    Browse other users' surveys

    Vote on surveys (one vote per user per question)

    See real-time results with percentages

Tech Stack:

    Backend: Spring Boot + JPA + REST APIs

    Database: Postgresql

    Front-end: ANgular with the help of ai like Deepseek, Claude ai, cursor and Vscode ai agents.    

How It Works:

    Users register and login

    Create surveys with multiple questions & answers

    Other users vote on survey answers

    See live results with vote counts and percentages

    Manage your content - edit or delete your surveys
